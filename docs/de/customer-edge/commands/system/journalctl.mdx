## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

Standard-`journalctl`-Argumente, jeweils als separates Array-Element. `-u vpm` ist
das, was Sie am häufigsten benötigen: `vpm` ist der Agent, der den Knoten registriert
und alles andere auf ihm verwaltet. Daher enthält sein Journal die Registrierungsfehler
mit Zeitstempeln und über Neustarts hinweg.

Nützliche Varianten:

| Argumente | Antworten |
| --- | --- |
| `-u vpm -n 200` | Was hat vpm zuletzt getan |
| `-u vpm --since "10 min ago"` | Was ist passiert, während ich es reproduziert habe |
| `-p err -n 100` | Fehler aus jeder Unit |
| `-u kubelet -n 200` | Warum der Kubernetes-Stack nicht funktioniert |

Bevorzugen Sie dies gegenüber [`docker-logs vpm`](../docker/), wenn Sie Zeitstempel
benötigen, einen Neustart überbrücken möchten oder vpm mit einer anderen Unit
korrelieren wollen.

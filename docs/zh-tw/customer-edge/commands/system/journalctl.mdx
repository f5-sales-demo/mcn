## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

標準的 `journalctl` 參數，每個參數為獨立的陣列元素。`-u vpm` 是最常用的選項：`vpm` 是負責註冊節點並管理其上所有事項的代理程式，因此其日誌是註冊失敗（含時間戳記）及跨重啟記錄的所在之處。

實用的變體：

| 參數 | 回答的問題 |
| --- | --- |
| `-u vpm -n 200` | vpm 最近在做什麼 |
| `-u vpm --since "10 min ago"` | 重現問題期間發生了什麼 |
| `-p err -n 100` | 所有單元的錯誤 |
| `-u kubelet -n 200` | Kubernetes 堆疊為何不健康 |

在需要時間戳記、需要跨重啟追蹤，或需要將 vpm 與其他單元關聯比對時，請優先使用此命令，而非 [`docker-logs vpm`](../docker/)。

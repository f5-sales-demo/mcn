## 節點執行兩個容器執行環境

這常讓人感到意外，而這也決定了哪個命令能回答您的問題。

- **Docker** 執行平台容器 — `vpm`、`argo_watch`、`site-console`。
- **CRI-O** 執行 Kubernetes 工作負載，透過 `crictl` 存取。

兩者同時運作，皆會回傳真實輸出，且互不替代。`docker-ps` 顯示三個容器並非損壞節點的部分視圖；而是 Docker 所執行內容的完整清單。如果您在尋找 `vpm`，它是一個 Docker 容器。如果您在尋找 Pod，則它屬於 CRI-O。

## 兩個命令使用不同的傳輸方式

`health` 與 `diagnosis` 屬於 `GLOBAL` 範圍：它們是對 `global` 路徑發出的 `GET` 請求，回傳 JSON 而非終端機文字，且**無法透過 `exec-user` 存取** — 將它們傳送至該處只會得到 `command not supported` 的回應，看起來像是該命令不存在。請參閱[除錯 API](../../access/debug-api/)。

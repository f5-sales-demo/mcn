</Aside>

## 僅適用於較新版本

當前版本（`crt-20260201-0179`）公開了 **43** 個指令——為嚴格的超集，未移除任何指令，且無任何中繼資料變更。以下九個指令為此租戶所缺少：

| 指令 | 類別 | 層級 |
| --- | --- | --- |
| `collect-database-stats` | 系統 | `ExecUser` |
| `iptables-lv` | 網路 | `ExecUser` |
| `marker-exists-NetworkManager` | 系統 | `Exec` |
| `marker-exists-crio` | 系統 | `Exec` |
| `marker-exists-kubelet` | 系統 | `Exec` |
| `systemctl-restart-NetworkManager` | 系統 | `Exec` |
| `systemctl-restart-crio` | 系統 | `Exec` |
| `systemctl-restart-kubelet` | 系統 | `Exec` |
| `systemctl-start-crio-prune` | 系統 | `Exec` |

這些指令僅列出名稱與層級，資料來源為針對該版本節點進行的目錄探索。此處無這些指令的擷取輸出，因為此租戶無法執行它們。請注意，九個指令中有四個會在線上資料平面下重新啟動服務。

<Aside type="note" title="偵測介面異動">
由於介面會隨軟體版本擴展，目錄會記錄其來源的版本，且 `scripts/capture-sitecli.sh --check` 會將版本變更與新增或移除的指令分開回報。當這些節點升級時，正是透過此檢查得知這九個指令已加入。
</Aside>

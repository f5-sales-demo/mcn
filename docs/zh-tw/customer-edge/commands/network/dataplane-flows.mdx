Argo 追蹤每一個連線。此節點上的表格共有 629,760 個條目，因此查詢方式比其內容更為重要。

## `flow-l-match`

幾乎在所有情況下都是您所需要的指令。接受一個地址，或一個地址加上連接埠。

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

每個流量的動作是關鍵所在：`F` 表示轉發、`D` 表示丟棄、`N` 表示 NAT。若流量存在且動作為 `D`，表示資料平面做出了明確的決策，此時應將排查方向轉向政策設定，而非連線能力。

## `flow-l`

完整傾印。

```bash
{"command":["flow-l"]}
```

```text file=../../../../_data/sitecli-flow-l.txt
```

<Aside type="caution" title="已截斷，且資料量極大">
上方的擷取內容已截斷至 1057 行中的前 60 行，而 1057 行本身是 API 自身的限制，並非整個表格的全部資料。除非您確實需要檢視整個表格，否則請使用 `flow-l-match`；即便使用完整傾印，表頭中的計數資訊——表格大小與條目數——也可能是唯一值得閱讀的部分。
</Aside>

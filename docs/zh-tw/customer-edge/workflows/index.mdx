[指令參考](../commands/) 是依據每個指令的功能來組織的。這些則是依據發生了什麼問題來組織的。

| 症狀 | 工作流程 |
| --- | --- |
| 網站從未上線，或從租戶中斷線 | [註冊](./registration/) |
| 路由未被公告或學習；VIP 無法連線 | [BGP](./bgp-diagnostics/) |
| 流量到達節點但未送達目的地 | [資料平面](./dataplane-diagnostics/) |

每個步驟都連結至記錄該指令的頁面。此處不重複任何內容，因此語法只有唯一的來源，不會與節點產生不一致。

## 開始之前

確認您目前使用的存取路徑，因為這會影響可執行的操作：

```bash
curl -sS -H "Authorization: APIToken $XCSH_API_TOKEN" \
  "$XCSH_API_URL/api/config/namespaces/system/sites/<site>" | jq -r '.spec.site_state'
```

`ONLINE` 表示 [除錯 API](../access/debug-api/) 可以回應。其他任何狀態則表示需使用[序列主控台](../access/serial-console/)，同時也代表您需要的是註冊工作流程。

<Aside type="note" title="Detectando a superfície em movimento">
Como a superfície cresce com o build do software, o catálogo registra o build do qual
ele provém, e `scripts/capture-sitecli.sh --check` reporta uma mudança de build
separadamente dos comandos adicionados ou removidos. Quando esses nós forem atualizados, essa verificação
é o que informa que esses nove chegaram.
</Aside>

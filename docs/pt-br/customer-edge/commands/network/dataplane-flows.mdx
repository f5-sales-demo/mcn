O Argo rastreia cada conexão. A tabela neste nó possui 629.760 entradas, portanto a forma
como você a consulta importa mais do que o que ela contém.

## `flow-l-match`

Quase sempre o que você precisa. Aceita um endereço, ou um endereço e porta.

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

A ação em cada fluxo é o ponto principal: `F` encaminhar, `D` descartar, `N` NAT. Um fluxo presente
com ação `D` significa que o plano de dados tomou uma decisão deliberada, o que redireciona você
para a política em vez de para a conectividade.

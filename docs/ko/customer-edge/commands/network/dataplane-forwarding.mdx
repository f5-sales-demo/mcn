Argo는 전달 상태를 Linux 커널과 별도로 유지합니다. [`ip`](../ip/)와 이 명령들이 서로 다른 내용을 표시할 경우, 실제 트래픽을 이동시키는 것은 이 명령들입니다.

## `rt`

VRF별 vRouter 라우트 테이블입니다.

```bash
{"command":["rt","--dump","2"]}
```

```text file=../../../../_data/sitecli-rt.txt
```

<Aside type="danger" title="VRF id는 BGP가 보고하는 것과 다릅니다">
`show-ip-bgp-summary`는 `vrf-id 3`을 출력합니다. 이는 FRR의 번호 체계이며 vRouter 테이블 id와는 다른 네임스페이스입니다. 이 값을 여기에 전달하면 노드가 손상된 것처럼 보이는 방식으로 실패합니다:

```text
vRouter(Response):  [No such file or directory (2)]
```

`--dump 0`에 대해서도 동일한 응답이 반환됩니다. 이 토폴로지에서 **VRF 2**는 채워진 inet4 테이블이며, VRF 1은 두 개의 라우트를 보유합니다. id를 모르는 경우, BGP 출력을 신뢰하기보다는 1부터 위쪽으로 순서대로 탐색하십시오.
</Aside>

## `nh`

넥스트 홉 테이블입니다. 모든 라우트는 넥스트 홉 id를 가리키며, 이를 통해 해석됩니다.

```bash
{"command":["nh","--list"]}
```

```text file=../../../../_data/sitecli-nh.txt
```

각 항목에는 `Type`과 해당 VRF가 포함됩니다. 이 노드들에서는 다음 비율로 여덟 가지 타입이 발생하며, 세 CE 모두에서 동일하게 집계됩니다:

```text
Tunnel 558   Encap 27   NAT 22   Vrf 16   Receive 14   Composite 4   Drop 2   Resolve 2
```

`Drop` 넥스트 홉으로 해석되는 라우트는 블랙홀이며, 프리픽스가 `rt`에 존재함에도 트래픽이 사라질 때마다 이 조합을 확인할 가치가 있습니다.

<Aside type="caution" title="위의 캡처는 잘린 것이므로 모든 타입을 포함하지 않습니다">
이는 3,849줄 중 처음 60줄입니다. 가장 흔한 타입인 `Tunnel`은 해당 60줄에 전혀 나타나지 않습니다 — 따라서 캡처를 전체 타입 목록으로 읽지 마십시오. 잘린 캡처에 타입이 없다고 해서 해당 노드에 그 타입이 없다고 결론 내리지 마십시오. 위의 집계는 잘리지 않은 응답에서 가져온 것입니다.
</Aside>

## `vif`

가상 인터페이스 테이블: 데이터 플레인이 바인딩하는 대상과 인터페이스별 카운터입니다.

```bash
{"command":["vif","--list"]}
```

```text file=../../../../_data/sitecli-vif.txt
```

상단의 플래그 범례는 한 번 읽어볼 가치가 있습니다 — `Vp`는 vhost 물리적 인터페이스를, `Dpdk`는 DPDK 관리 인터페이스를 표시합니다. 이를 통해 데이터 플레인이 예상한 인터페이스를 점유했는지 확인하고, 트래픽이 커널에 도달하지 않기 때문에 Linux가 표시하지 않는 RX 및 TX 카운터를 확인하십시오.

## `mpls`

```bash
execcli mpls --help
```

Argo MPLS 테이블입니다. **박스에서만** 접근 가능합니다 — `mpls`는 디버그 API에 없으므로, 위의 `rt`, `nh`, `vif`와 달리 [`execcli`](../../on-box/)를 통해 [SSH](../../../access/ssh/) 또는 [시리얼 콘솔](../../../access/serial-console/)이 필요합니다.

여기에는 캡처된 출력이 없습니다. 이 배포에서 CE는 BGP와 ECMP로 IPv4를 전달하며 MPLS 레이블을 사용하지 않으므로, 캡처하면 빈 테이블이 표시되어 아무것도 알려주지 않습니다. 해당 명령의 존재와 `--help` 인수 형식은 어플라이언스 자체의 자동 완성 메뉴에서 확인되었으며, 채워진 출력은 재현되지 않습니다.

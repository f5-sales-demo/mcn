## `netstat`

```bash
{"command":["netstat"]}
```

```text file=../../../../_data/sitecli-netstat.txt
```

이 명령이 잘 답해주는 두 가지 질문이 있습니다: 예상하는 프로세스가 예상하는 포트에서 수신 대기 중인지 여부, 그리고 노드가 컨트롤 플레인에 연결을 수립했는지 여부입니다. F5 인프라에 대한 아웃바운드 연결이 없는 CE는 다른 모든 것이 정상으로 보이더라도 등록되지 않는 노드입니다.

출력이 길기 때문에 — 위의 캡처는 축약된 것입니다 — 전체를 읽는 대신 인수를 전달하여 범위를 좁히십시오. 호스트명 열이 맞추기 위해 잘려 있다는 점에 주의하십시오. 전체 노드 이름으로 grep하여 아무것도 찾지 못하는 경우 이것이 원인일 수 있습니다.

데이터 플레인은 Argo이며, Linux 커널과 별도로 자체 포워딩 상태를 유지합니다. `ip`는 Linux가 인식하는 내용을 보여주고, `rt`, `nh`, `vif`는 실제로 트래픽을 포워딩하는 내용을 보여줍니다. 두 가지가 일치하지 않을 경우, 데이터 플레인이 우선합니다.

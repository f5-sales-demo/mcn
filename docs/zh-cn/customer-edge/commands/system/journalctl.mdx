## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

标准 `journalctl` 参数，每个参数作为独立的数组元素。`-u vpm` 是最常用的选项：`vpm` 是负责注册节点并管理其上所有其他组件的代理，因此其日志记录了注册失败的时间戳及跨重启的完整信息。

常用变体：

| 参数 | 用途 |
| --- | --- |
| `-u vpm -n 200` | 查看 vpm 最近的活动情况 |
| `-u vpm --since "10 min ago"` | 查看复现问题期间发生的事件 |
| `-p err -n 100` | 查看所有单元的错误信息 |
| `-u kubelet -n 200` | 诊断 Kubernetes 栈不健康的原因 |

当需要时间戳、希望跨重启查看日志，或需要将 vpm 与其他单元进行关联分析时，建议优先使用此方式，而非 [`docker-logs vpm`](../docker/)。

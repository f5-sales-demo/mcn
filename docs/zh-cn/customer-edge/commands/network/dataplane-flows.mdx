Argo 跟踪每一个连接。此节点上的表包含 629,760 条记录，因此查询方式比内容本身更为重要。

## `flow-l-match`

几乎始终是您所需要的命令。接受一个地址，或一个地址加端口。

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

每条流的动作是关键所在：`F` 表示转发，`D` 表示丢弃，`N` 表示 NAT。若某条流存在且动作为 `D`，表示数据平面做出了明确的决策，此时应将排查方向指向策略而非连通性。

## `flow-l`

```bash
{"command":["flow-l"]}
```

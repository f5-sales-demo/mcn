## `netstat`

```bash
{"command":["netstat"]}
```

```text file=../../../../_data/sitecli-netstat.txt
```

此命令可以很好地回答两个问题：您期望的进程是否正在监听您期望的端口，以及节点是否已与控制平面建立连接。若 CE 没有向 F5 基础设施建立任何出站连接，则该节点将无法注册，无论其他方面看起来多么正常。

输出内容较长——上方的抓取内容已经过裁剪——因此请传入参数进行缩小范围，而非通读全部内容。请注意，主机名列会被截断以适应显示宽度，如果您正在使用 grep 搜索完整节点名称却找不到结果，这一点需要特别留意。

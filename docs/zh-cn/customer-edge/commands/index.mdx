## 仅在较新版本中可用

当前构建版本（`crt-20260201-0179`）暴露了 **43** 个命令——严格来说是超集，无任何删除，也无元数据变更。以下九个命令在此租户中不可用：

| 命令 | 类别 | 层级 |
| --- | --- | --- |
| `collect-database-stats` | 系统 | `ExecUser` |
| `iptables-lv` | 网络 | `ExecUser` |
| `marker-exists-NetworkManager` | 系统 | `Exec` |
| `marker-exists-crio` | 系统 | `Exec` |
| `marker-exists-kubelet` | 系统 | `Exec` |
| `systemctl-restart-NetworkManager` | 系统 | `Exec` |
| `systemctl-restart-crio` | 系统 | `Exec` |
| `systemctl-restart-kubelet` | 系统 | `Exec` |
| `systemctl-start-crio-prune` | 系统 | `Exec` |

以上命令仅列出名称和层级，来源于针对该构建版本节点的目录发现。由于此租户无法运行这些命令，因此这里没有对应的捕获输出。请注意，九个命令中有四个会在线上数据平面下重启服务。

<Aside type="note" title="检测接口变化">
由于接口会随软件构建版本增长，目录会记录其来源的构建版本，而 `scripts/capture-sitecli.sh --check` 会将构建版本变更与命令的新增或删除分别报告。当这些节点升级后，正是通过该检查才能得知上述九个命令已到位。
</Aside>

[命令参考](../commands/) 按各命令的功能组织。本部分则按出现的问题组织。

| 症状 | 工作流 |
| --- | --- |
| 站点从未上线，或已从租户中断开 | [注册](./registration/) |
| 路由未被通告或学习；VIP 不可达 | [BGP](./bgp-diagnostics/) |
| 流量到达节点但未能送达 | [数据平面](./dataplane-diagnostics/) |

每个步骤均链接至记录该命令的页面。此处不重复任何内容，因此语法只有唯一的来源，不会与节点产生不一致。

## 开始之前

确认您当前所使用的访问路径，因为这决定了可执行的操作：

```bash
curl -sS -H "Authorization: APIToken $XCSH_API_TOKEN" \
  "$XCSH_API_URL/api/config/namespaces/system/sites/<site>" | jq -r '.spec.site_state'
```

`ONLINE` 表示 [调试 API](../access/debug-api/) 可以响应。任何其他状态均表示需使用[串行控制台](../access/serial-console/)，同时也意味着注册工作流是您需要使用的流程。

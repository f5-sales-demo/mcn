Argo प्रत्येक अस्वीकृति को कारण सहित गिनता है। यह सबसे तेज़ तरीका है यह बताने का कि "पैकेट कभी पहुँचा ही नहीं" और "पैकेट पहुँचा और जानबूझकर ड्रॉप किया गया" के बीच अंतर करने का।

## `dropstats-non-zero`

इसे प्राथमिकता दें। यह केवल वे काउंटर दिखाता है जो सक्रिय हुए हैं, जो पैंसठ की बजाय कुछ ही पंक्तियाँ होती हैं।

```bash
{"command":["dropstats-non-zero"]}
```

```text file=../../../../_data/sitecli-dropstats-non-zero.txt
```

<Aside type="caution" title="नॉन-ज़ीरो का मतलब टूटा हुआ नहीं है">
ये डेटा प्लेन शुरू होने के बाद से की जीवनकाल कुल संख्याएँ हैं, दर नहीं। `Flow Action
Drop` नीति को अपना काम करते हुए गिनता है। महत्वपूर्ण यह है कि जब आप समस्या को पुनः उत्पन्न कर रहे हों तो कोई काउंटर *बढ़ रहा है* या नहीं, इसलिए कमांड को दो बार चलाएँ और तुलना करें।
</Aside>

## `dropstats`

शून्य सहित प्रत्येक काउंटर।

```bash
{"command":["dropstats"]}
```

```text file=../../../../_data/sitecli-dropstats.txt
```

एक बार पूरा पढ़ने लायक है, यह जानने के लिए कि कौन से कारण मौजूद हैं। उसके बाद, नॉन-ज़ीरो वेरिएंट ही उपयोग करने वाला है।

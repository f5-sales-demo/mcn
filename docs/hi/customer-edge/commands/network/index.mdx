चौंतीस में से इक्कीस कमांड। ये उस लेयर के अनुसार विभाजित होते हैं जिस पर आपको संदेह है।

| यदि आपको संदेह है | यहाँ से शुरू करें |
| --- | --- |
| साइट रूट एडवर्टाइज़ या लर्न नहीं कर रही | [BGP](./bgp/) |
| रीजनल एज से टनल डाउन है | [IPsec](./ipsec/) |
| ट्रैफ़िक आता है लेकिन डिस्कार्ड हो जाता है | [ड्रॉप स्टैटिस्टिक्स](./dataplane-drops/) |
| कोई विशेष कनेक्शन अजीब व्यवहार करता है | [फ़्लो टेबल](./dataplane-flows/) |
| किसी पूरे प्रीफिक्स के लिए फॉरवर्डिंग गलत है | [रूट और नेक्स्ट हॉप](./dataplane-forwarding/) |
| कोई इंटरफेस डाउन या गलत कॉन्फ़िगर है | [इंटरफेस](./ip/) |
| नाम रिज़ॉल्यूशन | [dig](./dig/) |
| नोड से बाहर पहुँच | [curl](./curl/) |
| सॉकेट और लिसनर | [netstat](./netstat/) |
| सर्टिफ़िकेट या ऑथ को तोड़ने वाला क्लॉक स्क्यू | [chronyc-sources](./chronyc-sources/) |

डेटा प्लेन Argo है, और यह Linux कर्नेल से अलग अपनी फॉरवर्डिंग स्थिति बनाए रखता है। `ip` आपको दिखाता है कि Linux क्या मानता है; `rt`, `nh` और `vif` आपको दिखाते हैं कि ट्रैफ़िक वास्तव में क्या फॉरवर्ड करता है। जब इन दोनों में असहमति हो, तो डेटा प्लेन जीतता है।

CE BGP के लिए FRR चलाता है। इस टोपोलॉजी पर यह दो Azure Route Server
इंस्टेंस के साथ पीयर करता है, VIP विज्ञापित करता है, और VNet प्रीफ़िक्स सीखता है।

## `show-ip-bgp-summary`

यहाँ से शुरू करें। एक स्क्रीन बताती है कि पीयरिंग चालू है या नहीं और यह कितने समय से
स्थिर है।

```bash
{"command":["show-ip-bgp-summary"]}
```

```text file=../../../../_data/sitecli-show-ip-bgp-summary.txt
```

पहले `State/PfxRcd` पढ़ें। एक संख्या प्राप्त प्रीफ़िक्स की गिनती है और इसका अर्थ है कि
सेशन स्थापित है; कोई भी अन्य मान — `Active`, `Connect`, `Idle` — एक ऐसा सेशन है
जो चालू नहीं है। `Up/Down` दर्शाता है कि वर्तमान स्थिति कितने समय से बनी है, इसलिए
जो सेशन बार-बार रीसेट होता है उसका मान संदिग्ध रूप से छोटा होता है।

<Aside type="caution" title="यहाँ का vrf id वह नहीं है जो rt चाहता है">
यह आउटपुट `vrf-id 3` रिपोर्ट करता है। यह FRR की नंबरिंग है। Argo डेटा प्लेन एक
अलग table id उपयोग करता है, और FRR की संख्या को
[`rt --dump`](../dataplane-forwarding/) को पास करने पर `No such file or directory` मिलता है, जो
गलत आर्गुमेंट की बजाय टूटे हुए नोड जैसा दिखता है।
</Aside>

## `show-ip-bgp`

पूर्ण तालिका, जिसमें best-path चयन दृश्यमान है।

```bash
{"command":["show-ip-bgp"]}
```

```text file=../../../../_data/sitecli-show-ip-bgp.txt
```

`*` एक वैध मार्ग है, `>` चयनित सर्वोत्तम पथ है, `=` एक multipath सदस्य है। एक
प्रीफ़िक्स की दो प्रविष्टियाँ जो दोनों `*=` चिह्नित हैं, इसका अर्थ है कि ECMP प्रभावी है,
जो इस टोपोलॉजी पर अभीष्ट स्थिति है।

## `show-ip-bgp-neighbors`

प्रति-पड़ोसी विवरण: सहमत की गई क्षमताएँ, टाइमर, संदेश काउंटर और अंतिम रीसेट का कारण।

```bash
{"command":["show-ip-bgp-neighbors"]}
```

इसका उपयोग तब करें जब सारांश किसी सेशन के बार-बार टूटने को दर्शाए और आपको जानना हो कि क्यों।
`Last reset` और उसका कारण उपयोगी पंक्तियाँ हैं।

<Aside type="note" title="इस पृष्ठ पर अभी तक कोई कैप्चर किया गया आउटपुट नहीं है">
यह कैप्चर तब तक प्रतिबद्ध नहीं किया जा सकता जब तक `f5-sales-demo/docs-control#795` लागू न हो जाए। FRR
अपनी Graceful Restart लाइन में एक शब्द की वर्तनी गलत करता है, और `codespell` फ़ाइल को अस्वीकार कर देता है।

कैप्चर किए गए टेक्स्ट को सुधारना इस दस्तावेज़ीकरण को ऐसे आउटपुट का वर्णन करवा देगा जो कभी हुआ ही नहीं,
इसलिए इसे upstream में ठीक किया जा रहा है। तब तक अपने स्वयं के
नोड पर कमांड चलाएँ।
</Aside>

यह नोड अपने पीयरों को क्या बता रहा है, न कि वह क्या जानता है।

```bash
{"command":["show-ip-bgp-neighbors-advertised-route"]}
```

```text file=../../../../_data/sitecli-show-ip-bgp-neighbors-advertised-route.txt
```

यह कमांड "VIP VNet से पहुँचनीय नहीं है" की स्थिति के लिए है। यदि VIP यहाँ
अनुपस्थित है, तो समस्या इस नोड पर है और पीयर को देखने से कोई मदद नहीं मिलेगी।

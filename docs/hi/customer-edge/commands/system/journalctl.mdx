## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

मानक `journalctl` तर्क, प्रत्येक एक अलग ऐरे तत्व के रूप में। `-u vpm` वह है
जिसकी आपको सबसे अधिक आवश्यकता होती है: `vpm` वह एजेंट है जो नोड को पंजीकृत करता है और उस पर
बाकी सब कुछ प्रबंधित करता है, इसलिए इसका जर्नल वह स्थान है जहाँ पंजीकरण विफलताएँ
टाइमस्टैम्प के साथ और पुनः आरंभ के दौरान दिखाई देती हैं।

उपयोगी वेरिएंट:

| तर्क | उत्तर |
| --- | --- |
| `-u vpm -n 200` | vpm हाल ही में क्या कर रहा है |
| `-u vpm --since "10 min ago"` | जब मैंने इसे पुनः उत्पन्न किया तब क्या हुआ |
| `-p err -n 100` | हर यूनिट से त्रुटियाँ |
| `-u kubelet -n 200` | Kubernetes स्टैक अस्वस्थ क्यों है |

जब आपको टाइमस्टैम्प की आवश्यकता हो, पुनः आरंभ को पार करना हो, या किसी अन्य यूनिट के विरुद्ध vpm को सहसंबद्ध करना हो, तो [`docker-logs vpm`](../docker/) के बजाय इसे प्राथमिकता दें।

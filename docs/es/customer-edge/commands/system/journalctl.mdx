## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

Argumentos estándar de `journalctl`, cada uno como un elemento de array separado. `-u vpm` es el que
necesitará con más frecuencia: `vpm` es el agente que registra el nodo y gestiona
todo lo demás en él, por lo que su diario es donde aparecen los fallos de registro con
marcas de tiempo y a través de reinicios.

Variantes útiles:

| Argumentos | Respuestas |
| --- | --- |
| `-u vpm -n 200` | Qué ha estado haciendo vpm recientemente |
| `-u vpm --since "10 min ago"` | Qué ocurrió mientras lo reproducía |
| `-p err -n 100` | Errores de todas las unidades |
| `-u kubelet -n 200` | Por qué el stack de Kubernetes no está en buen estado |

Prefiera este sobre [`docker-logs vpm`](../docker/) cuando necesite marcas de tiempo, desee
abarcar un reinicio, o quiera correlacionar vpm con otra unidad.

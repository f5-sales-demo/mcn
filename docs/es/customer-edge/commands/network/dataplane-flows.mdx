Argo realiza un seguimiento de cada conexión. La tabla en este nodo tiene 629.760 entradas, por lo que la forma en que se consulta importa más que su contenido.

## `flow-l-match`

Casi siempre es la opción que necesita. Acepta una dirección, o una dirección y puerto.

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

La acción en cada flujo es lo relevante: `F` reenviar, `D` descartar, `N` NAT. Un flujo presente con acción `D` significa que el plano de datos tomó una decisión deliberada, lo que redirige la atención hacia la política en lugar de hacia la conectividad.

Argo นับทุกการทิ้งแพ็กเก็ตตามเหตุผล นี่คือวิธีที่เร็วที่สุดในการแยกแยะระหว่าง "แพ็กเก็ตไม่เคยมาถึง" กับ "แพ็กเก็ตมาถึงแล้วแต่ถูกทิ้งโดยตั้งใจ"

## `dropstats-non-zero`

แนะนำให้ใช้ตัวเลือกนี้ก่อน เนื่องจากแสดงเฉพาะตัวนับที่มีค่า ซึ่งจะแสดงผลเพียงไม่กี่บรรทัดแทนที่จะเป็นหกสิบห้าบรรทัด

```bash
{"command":["dropstats-non-zero"]}
```

```text file=../../../../_data/sitecli-dropstats-non-zero.txt
```

<Aside type="caution" title="ค่าที่ไม่ใช่ศูนย์ไม่ได้หมายความว่ามีปัญหา">
ค่าเหล่านี้คือผลรวมตลอดช่วงเวลาตั้งแต่ระนาบข้อมูลเริ่มทำงาน ไม่ใช่อัตรา `Flow Action
Drop` คือการนับนโยบายที่ทำงานตามปกติ สิ่งสำคัญคือต้องดูว่าตัวนับ *เพิ่มขึ้น* หรือไม่ขณะที่คุณจำลองปัญหา ดังนั้นให้รันคำสั่งสองครั้งแล้วเปรียบเทียบ
</Aside>

## `dropstats`

ตัวนับทั้งหมดรวมถึงค่าที่เป็นศูนย์

```bash
{"command":["dropstats"]}
```

```text file=../../../../_data/sitecli-dropstats.txt
```

ควรอ่านทั้งหมดหนึ่งครั้งเพื่อทำความเข้าใจว่ามีเหตุผลใดบ้างที่เป็นไปได้ หลังจากนั้น ให้ใช้ตัวเลือก non-zero เป็นหลัก

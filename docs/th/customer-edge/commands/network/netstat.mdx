## `netstat`

```bash
{"command":["netstat"]}
```

```text file=../../../../_data/sitecli-netstat.txt
```

คำถามสองข้อที่คำสั่งนี้ตอบได้ดี ได้แก่ กระบวนการที่คุณคาดหวังกำลังฟังอยู่บนพอร์ตที่คาดหวังหรือไม่ และโหนดได้สร้างการเชื่อมต่อไปยังระนาบควบคุม (control plane) หรือไม่ CE ที่ไม่มีการเชื่อมต่อขาออกที่สร้างขึ้นไปยังโครงสร้างพื้นฐาน F5 เลย คือโหนดที่จะไม่ลงทะเบียน ไม่ว่าสิ่งอื่นจะดูสมบูรณ์เพียงใด

ผลลัพธ์มีความยาวมาก — ข้อมูลที่บันทึกไว้ข้างต้นถูกตัดทอนแล้ว — ดังนั้นควรส่งอาร์กิวเมนต์เพื่อจำกัดขอบเขตแทนที่จะอ่านทั้งหมด โปรดทราบว่าคอลัมน์ชื่อโฮสต์จะถูกตัดให้พอดีกับหน้าจอ ซึ่งมีความสำคัญหากคุณกำลังใช้ grep เพื่อค้นหาชื่อโหนดแบบเต็มแล้วไม่พบสิ่งใด

## `chronyc-sources`

```bash
{"command":["chronyc-sources"]}
```

```text file=../../../../_data/sitecli-chronyc-sources.txt
```

อักขระนำหน้าในแต่ละบรรทัดคือสถานะ: `*` คือแหล่งที่เลือกใช้งานอยู่ในปัจจุบัน, `+` คือทางเลือกที่ยอมรับได้, `-` คือแหล่งที่ถูกยกเว้นโดยอัลกอริทึมการเลือก และ `?` คือแหล่งที่ไม่สามารถเข้าถึงได้ กรณีที่ดีต้องมี `*` อยู่หนึ่งตัวพอดี

`Reach` คือรีจิสเตอร์ฐานแปดของการสำรวจแปดครั้งล่าสุด ดังนั้น `377` หมายความว่าการสำรวจทั้งแปดครั้งสำเร็จ ค่าที่ไม่ใช่ `377` หมายความว่ามีการสำรวจที่สูญหาย `LastRx` แสดงระยะเวลาที่ผ่านไปนับตั้งแต่แหล่งตอบสนองครั้งล่าสุด

ควรตรวจสอบตั้งแต่เนิ่น ๆ เมื่อการยืนยันตัวตนหรือ TLS ล้มเหลวโดยไม่มีสาเหตุที่มองเห็นได้: โหนดที่นาฬิกาเบี่ยงเบนมากพอจะปฏิเสธใบรับรองที่ถูกต้องและถูกปฏิเสธโทเค็น ซึ่งข้อผิดพลาดที่เกิดขึ้นมักไม่กล่าวถึงเวลาเลย

Argo ติดตามทุกการเชื่อมต่อ ตารางบนโหนดนี้มี 629,760 รายการ ดังนั้นวิธีที่คุณ
ใช้ค้นหาจึงสำคัญกว่าเนื้อหาที่อยู่ในตาราง

## `flow-l-match`

แทบจะเป็นคำสั่งที่คุณต้องการเสมอ รับค่าแอดเดรส หรือแอดเดรสพร้อมพอร์ต

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

การดำเนินการบนแต่ละการไหลคือจุดสำคัญ: `F` ส่งต่อ (forward), `D` ทิ้ง (drop), `N` NAT หากพบการไหลที่มีการดำเนินการ `D`
หมายความว่าระนาบข้อมูลได้ตัดสินใจโดยเจตนา ซึ่งชี้ให้คุณไปตรวจสอบนโยบายแทนที่จะเป็นการเชื่อมต่อ

## `flow-l`

การดัมป์แบบเต็ม

```bash
{"command":["flow-l"]}
```

```text file=../../../../_data/sitecli-flow-l.txt
```

<Aside type="caution" title="ถูกตัดทอนและมีขนาดใหญ่มาก">
ข้อมูลที่บันทึกไว้ข้างต้นถูกตัดทอนเหลือเพียง 60 บรรทัดแรกจากทั้งหมด 1,057 บรรทัด และ 1,057 บรรทัดนั้นเป็นขีดจำกัดของ API เอง ไม่ใช่ตารางทั้งหมด ใช้ `flow-l-match` เว้นแต่คุณจำเป็นต้องสำรวจตารางทั้งหมดจริงๆ และคาดว่าจำนวนในส่วนหัว — ขนาดตารางและจำนวนรายการ — จะเป็นส่วนเดียวที่คุ้มค่าต่อการอ่านเมื่อคุณดำเนินการดังกล่าว
</Aside>

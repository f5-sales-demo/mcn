ยี่สิบเอ็ดจากสามสิบสี่คำสั่ง แบ่งตามชั้นที่คุณสงสัย

| หากคุณสงสัยว่า | เริ่มที่ |
| --- | --- |
| ไซต์ไม่ได้ประกาศหรือเรียนรู้เส้นทาง | [BGP](./bgp/) |
| อุโมงค์ไปยัง regional edge ขัดข้อง | [IPsec](./ipsec/) |
| ทราฟฟิกเดินทางมาถึงแต่ถูกทิ้ง | [สถิติการทิ้งแพ็กเก็ต](./dataplane-drops/) |
| การเชื่อมต่อเฉพาะรายการมีพฤติกรรมผิดปกติ | [ตารางโฟลว์](./dataplane-flows/) |
| การส่งต่อผิดพลาดสำหรับ prefix ทั้งหมด | [เส้นทางและ next hops](./dataplane-forwarding/) |
| อินเทอร์เฟซขัดข้องหรือกำหนดค่าไม่ถูกต้อง | [อินเทอร์เฟซ](./ip/) |
| การแปลงชื่อ | [dig](./dig/) |
| การเข้าถึงจากนอกโหนด | [curl](./curl/) |
| ซ็อกเก็ตและผู้รับฟัง | [netstat](./netstat/) |
| ความคลาดเคลื่อนของนาฬิกาทำให้ใบรับรองหรือการยืนยันตัวตนล้มเหลว | [chronyc-sources](./chronyc-sources/) |

ระนาบข้อมูลคือ Argo และจะเก็บสถานะการส่งต่อของตัวเองแยกจาก
Linux kernel `ip` แสดงสิ่งที่ Linux เชื่อ ส่วน `rt`, `nh` และ `vif` แสดง
สิ่งที่ส่งต่อทราฟฟิกจริง เมื่อทั้งสองไม่ตรงกัน ระนาบข้อมูลจะเป็นฝ่ายชนะ

## มีเฉพาะในบิลด์ใหม่กว่าเท่านั้น

บิลด์ปัจจุบัน (`crt-20260201-0179`) เปิดเผย **43** คำสั่ง ซึ่งเป็น superset อย่างเคร่งครัด โดยไม่มีการลบและไม่มีการเปลี่ยนแปลงข้อมูล metadata เก้าคำสั่งที่ tenant นี้ไม่มี:

| คำสั่ง | หมวดหมู่ | Tier |
| --- | --- | --- |
| `collect-database-stats` | ระบบ | `ExecUser` |
| `iptables-lv` | เครือข่าย | `ExecUser` |
| `marker-exists-NetworkManager` | ระบบ | `Exec` |
| `marker-exists-crio` | ระบบ | `Exec` |
| `marker-exists-kubelet` | ระบบ | `Exec` |
| `systemctl-restart-NetworkManager` | ระบบ | `Exec` |
| `systemctl-restart-crio` | ระบบ | `Exec` |
| `systemctl-restart-kubelet` | ระบบ | `Exec` |
| `systemctl-start-crio-prune` | ระบบ | `Exec` |

คำสั่งเหล่านี้ถูกระบุด้วยชื่อและระดับเท่านั้น จากการค้นพบแคตตาล็อกกับโหนดบนบิลด์นั้น ไม่มีผลลัพธ์ที่บันทึกไว้สำหรับคำสั่งเหล่านี้ที่นี่ เนื่องจาก tenant นี้ไม่สามารถรันคำสั่งเหล่านั้นได้ โปรดทราบว่าสี่ในเก้าคำสั่งนั้นจะรีสตาร์ทบริการภายใต้ data plane ที่ใช้งานอยู่

<Aside type="note" title="การตรวจจับพื้นผิวที่เปลี่ยนแปลง">
เนื่องจากพื้นผิวเพิ่มขึ้นตามบิลด์ซอฟต์แวร์ แคตตาล็อกจึงบันทึกบิลด์ที่มาจาก และ `scripts/capture-sitecli.sh --check` รายงานการเปลี่ยนแปลงบิลด์แยกจากคำสั่งที่เพิ่มหรือลบออก เมื่อโหนดเหล่านี้ได้รับการอัปเกรด การตรวจสอบนั้นจะเป็นสิ่งที่บอกให้รู้ว่าเก้าคำสั่งนี้ได้มาถึงแล้ว
</Aside>

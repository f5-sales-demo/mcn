## `journalctl`

```bash
{"command":["journalctl","-u","vpm","-n","200"]}
```

อาร์กิวเมนต์มาตรฐานของ `journalctl` แต่ละรายการเป็นองค์ประกอบอาร์เรย์แยกต่างหาก `-u vpm` คือสิ่งที่คุณต้องการบ่อยที่สุด: `vpm` คือตัวแทนที่ลงทะเบียนโหนดและจัดการทุกอย่างบนโหนดนั้น ดังนั้นบันทึกของมันจึงเป็นที่ที่ความล้มเหลวในการลงทะเบียนปรากฏพร้อมกับการประทับเวลาและข้ามการรีสตาร์ท

รูปแบบที่มีประโยชน์:

| อาร์กิวเมนต์ | คำตอบ |
| --- | --- |
| `-u vpm -n 200` | vpm กำลังทำอะไรอยู่เมื่อเร็วๆ นี้ |
| `-u vpm --since "10 min ago"` | เกิดอะไรขึ้นขณะที่ฉันจำลองเหตุการณ์ |
| `-p err -n 100` | ข้อผิดพลาดจากทุกหน่วย |
| `-u kubelet -n 200` | เหตุใด Kubernetes stack จึงไม่ปกติ |

ควรใช้สิ่งนี้แทน [`docker-logs vpm`](../docker/) เมื่อคุณต้องการการประทับเวลา ต้องการครอบคลุมช่วงการรีสตาร์ท หรือต้องการเปรียบเทียบ vpm กับหน่วยอื่น

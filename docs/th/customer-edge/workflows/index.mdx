[ข้อมูลอ้างอิงคำสั่ง](../commands/) จัดระเบียบตามสิ่งที่คำสั่งแต่ละคำสั่งทำ ส่วนนี้จัดระเบียบตามสิ่งที่เกิดขึ้นผิดพลาด

| อาการ | เวิร์กโฟลว์ |
| --- | --- |
| ไซต์ไม่เคยออนไลน์ หรือหลุดออกจากเทแนนต์ | [การลงทะเบียน](./registration/) |
| เส้นทางไม่ถูกโฆษณาหรือเรียนรู้ VIP ไม่สามารถเข้าถึงได้ | [BGP](./bgp-diagnostics/) |
| ทราฟฟิกไปถึงโหนดแต่ไม่มาถึงปลายทาง | [ระนาบข้อมูล](./dataplane-diagnostics/) |

แต่ละขั้นตอนเชื่อมโยงไปยังหน้าที่จัดทำเอกสารคำสั่งนั้น ไม่มีการกล่าวซ้ำที่นี่ ดังนั้นไวยากรณ์จึงมีที่เดียวและไม่สามารถเกิดความไม่สอดคล้องกับโหนดได้

## ก่อนเริ่มเวิร์กโฟลว์ใด ๆ

ระบุเส้นทางการเข้าถึงที่คุณใช้งานอยู่ เนื่องจากมีผลต่อสิ่งที่เป็นไปได้:

```bash
curl -sS -H "Authorization: APIToken $XCSH_API_TOKEN" \
  "$XCSH_API_URL/api/config/namespaces/system/sites/<site>" | jq -r '.spec.site_state'
```

`ONLINE` หมายความว่า [debug API](../access/debug-api/) จะตอบสนอง ค่าอื่นใดหมายความว่าต้องใช้ [serial console](../access/serial-console/) และยังหมายความว่าเวิร์กโฟลว์การลงทะเบียนคือสิ่งที่คุณต้องการ

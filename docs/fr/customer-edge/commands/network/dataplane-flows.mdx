Argo suit chaque connexion. La table sur ce nœud contient 629 760 entrées, donc la
façon dont vous l'interrogez importe plus que ce qu'elle contient.

## `flow-l-match`

C'est presque toujours ce que vous souhaitez. Prend une adresse, ou une adresse et un port.

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

L'action sur chaque flux est l'essentiel : `F` pour transférer, `D` pour abandonner, `N` pour NAT. Un flux présent
avec l'action `D` signifie que le plan de données a pris une décision délibérée, ce qui vous redirige
vers la politique plutôt que vers la connectivité.

يُنظَّم [مرجع الأوامر](../commands/) وفقاً لما يقوم به كل أمر. أما هذه المسارات
فمنظمة وفقاً لما أصاب النظام من خلل.

| العَرَض | مسار العمل |
| --- | --- |
| لم يتصل الموقع بالإنترنت أبداً، أو انقطع اتصاله بالمستأجر | [التسجيل](./registration/) |
| المسارات غير معلنة أو غير متعلمة؛ وعنوان VIP يتعذر الوصول إليه | [BGP](./bgp-diagnostics/) |
| حركة المرور تصل إلى العقدة لكنها لا تستقر | [مستوى البيانات](./dataplane-diagnostics/) |

كل خطوة ترتبط بالصفحة التي توثق الأمر. لا يُعاد ذكر أي شيء هنا،
وبذلك يكون لبناء الجملة موضع واحد بالتحديد ولا يمكن أن يخرج عن الاتساق مع العقدة.

## قبل أي منها

حدِّد مسار الوصول الذي تستخدمه، لأن ذلك يؤثر على ما هو ممكن:

```bash
curl -sS -H "Authorization: APIToken $XCSH_API_TOKEN" \
  "$XCSH_API_URL/api/config/namespaces/system/sites/<site>" | jq -r '.spec.site_state'
```

`ONLINE` يعني أن [واجهة API للتصحيح](../access/debug-api/) ستستجيب. أي شيء آخر يعني
[وحدة التحكم التسلسلية](../access/serial-console/)، ويعني أيضاً أن مسار عمل التسجيل هو ما تحتاجه.

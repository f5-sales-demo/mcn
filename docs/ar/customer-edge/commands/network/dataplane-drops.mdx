يحسب Argo كل عملية تجاهل مع ذكر سببها. هذه هي الطريقة الأسرع للتمييز بين "الحزمة لم تصل أبداً" و"الحزمة وصلت وأُسقطت عن قصد".

## `dropstats-non-zero`

يُفضَّل استخدام هذا الأمر. إذ يعرض فقط العدّادات التي سجّلت قيماً، مما يجعله بضعة أسطر بدلاً من خمسة وستين.

```bash
{"command":["dropstats-non-zero"]}
```

```text file=../../../../_data/sitecli-dropstats-non-zero.txt
```

<Aside type="caution" title="القيمة غير الصفرية لا تعني وجود خلل">
هذه إجماليات تراكمية منذ بدء تشغيل مستوى البيانات، وليست معدلات. `Flow Action
Drop` يحسب ما تقوم به السياسة من عملها الطبيعي. ما يهم هو ما إذا كان العدّاد *يتزايد*
أثناء إعادة إنتاج المشكلة، لذا شغّل الأمر مرتين وقارن النتيجتين.
</Aside>

## `dropstats`

جميع العدّادات بما فيها الصفرية.

```bash
{"command":["dropstats"]}
```

```text file=../../../../_data/sitecli-dropstats.txt
```

يستحق القراءة الكاملة مرةً واحدة، للتعرف على الأسباب الموجودة. بعد ذلك، النسخة غير الصفرية هي التي ينبغي استخدامها.

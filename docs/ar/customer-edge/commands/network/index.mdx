واحد وعشرون من أصل أربعة وثلاثين أمرًا. تنقسم وفقًا للطبقة التي تشك فيها.

| إذا كنت تشك في | ابدأ من |
| --- | --- |
| الموقع لا يُعلن عن المسارات أو لا يتعلمها | [BGP](./bgp/) |
| النفق إلى الحافة الإقليمية معطّل | [IPsec](./ipsec/) |
| تصل حركة المرور لكنها تُرفض | [إحصائيات الإسقاط](./dataplane-drops/) |
| اتصال معين يتصرف بشكل غريب | [جدول التدفق](./dataplane-flows/) |
| إعادة التوجيه خاطئة لبادئة كاملة | [المسارات والقفزات التالية](./dataplane-forwarding/) |
| واجهة معطّلة أو مُهيأة بشكل خاطئ | [الواجهات](./ip/) |
| تحليل الأسماء | [dig](./dig/) |
| إمكانية الوصول من العقدة | [curl](./curl/) |
| المقابس والمستمعون | [netstat](./netstat/) |
| انحراف الساعة يُعطّل الشهادات أو المصادقة | [chronyc-sources](./chronyc-sources/) |

مستوى البيانات هو Argo، ويحتفظ بحالة إعادة توجيه خاصة به منفصلة عن
نواة Linux. يُظهر لك `ip` ما تعتقده Linux؛ بينما تُظهر لك `rt` و`nh` و`vif`
ما يُعيد توجيه حركة المرور فعليًا. عندما يختلف الاثنان، يفوز مستوى البيانات.

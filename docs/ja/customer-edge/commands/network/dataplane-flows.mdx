Argo はすべての接続を追跡します。このノードのテーブルには 629,760 件のエントリが含まれているため、クエリの方法はその内容よりも重要です。

## `flow-l-match`

ほとんどの場合、これが必要なコマンドです。アドレス、またはアドレスとポートを引数に取ります。

```bash
{"command":["flow-l-match","100.127.192.10:53"]}
```

```text file=../../../../_data/sitecli-flow-l-match.txt
```

各フローのアクションが重要です: `F` は転送、`D` はドロップ、`N` は NAT を意味します。アクション `D` が設定されたフローが存在する場合、データプレーンが意図的な判断を下したことを示しており、調査先を接続性ではなくポリシーに向けることになります。

## `flow-l`

完全なダンプです。

```bash
{"command":["flow-l"]}
```


<Aside type="caution" title="切り詰められており、かつ膨大なサイズ">
上記のキャプチャは 1057 行中の最初の 60 行に切り詰められており、さらにその 1057 行自体も API の上限であり、テーブル全体ではありません。テーブル全体を調査する必要が本当にある場合を除き、`flow-l-match` を使用してください。また、実際に使用する際は、ヘッダーのカウント（テーブルサイズとエントリ数）だけが参照する価値のある部分になることを想定してください。
</Aside>

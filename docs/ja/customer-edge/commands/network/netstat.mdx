## `netstat`

```bash
{"command":["netstat"]}
```

```text file=../../../../_data/sitecli-netstat.txt
```

このコマンドが明確に答える問いは2つあります。期待するプロセスが期待するポートでリスニングしているかどうか、そしてノードがコントロールプレーンへの接続を確立しているかどうかです。F5 インフラストラクチャへの確立済みアウトバウンド接続が1つもない CE は、他のすべてが正常に見えていても、登録されないノードです。

出力は長く（上記のキャプチャはトリミング済みです）、全体を読むのではなく引数を指定して絞り込んでください。ホスト名列は収まるように切り詰められることに注意してください。これは、完全なノード名で grep して何も見つからない場合に重要になります。

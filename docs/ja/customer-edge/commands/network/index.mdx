34コマンド中21コマンドを収録しています。疑いのあるレイヤーごとに分類されています。

| 疑いのある箇所 | 開始地点 |
| --- | --- |
| サイトがルートをアドバタイズまたは学習していない | [BGP](./bgp/) |
| リージョナルエッジへのトンネルがダウンしている | [IPsec](./ipsec/) |
| トラフィックは届いているが破棄されている | [ドロップ統計](./dataplane-drops/) |
| 特定の接続の動作が異常 | [フローテーブル](./dataplane-flows/) |
| プレフィックス全体で転送が正しくない | [ルートとネクストホップ](./dataplane-forwarding/) |
| インターフェイスがダウンまたは設定ミス | [インターフェイス](./ip/) |
| 名前解決 | [dig](./dig/) |
| ノード外への到達性 | [curl](./curl/) |
| ソケットとリスナー | [netstat](./netstat/) |
| 証明書または認証を壊すクロックスキュー | [chronyc-sources](./chronyc-sources/) |

データプレーンはArgoであり、Linuxカーネルとは独立した独自の転送状態を保持しています。`ip`はLinuxが認識している内容を表示し、`rt`、`nh`、`vif`は実際にトラフィックを転送している内容を表示します。両者が一致しない場合、データプレーンが優先されます。

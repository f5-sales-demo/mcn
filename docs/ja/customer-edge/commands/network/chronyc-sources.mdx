## `chronyc-sources`

```bash
{"command":["chronyc-sources"]}
```

```text file=../../../../_data/sitecli-chronyc-sources.txt
```

各行の先頭の文字は状態を示します。`*` は現在選択されているソース、`+` は許容可能な代替ソース、`-` は選択アルゴリズムによって除外されたソース、`?` は到達不能なソースを意味します。`*` がちょうど1つ存在するのが正常な状態です。

`Reach` は直近8回のポーリング結果を示す8進数のレジスタです。`377` はすべての8回が成功したことを意味します。`377` 以外の値はポーリングが失われていることを示します。`LastRx` はそのソースが最後に応答した時刻からの経過時間を示します。

認証またはTLSが明らかな原因なく失敗している場合に早期に確認する価値があります。クロックが十分にドリフトしたノードは有効な証明書を拒否し、そのトークンも拒否されますが、その際に発生するエラーに時刻が言及されることはほとんどありません。

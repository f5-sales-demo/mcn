## 新しいビルドでのみ利用可能

現在のビルド (`crt-20260201-0179`) は **43** 個のコマンドを公開しており、削除や変更されたメタデータはなく、完全な上位互換セットとなっています。このテナントが持っていない 9 つのコマンドは以下の通りです：

| コマンド | カテゴリ | ティア |
| --- | --- | --- |
| `collect-database-stats` | System | `ExecUser` |
| `iptables-lv` | Network | `ExecUser` |
| `marker-exists-NetworkManager` | System | `Exec` |
| `marker-exists-crio` | System | `Exec` |
| `marker-exists-kubelet` | System | `Exec` |
| `systemctl-restart-NetworkManager` | System | `Exec` |
| `systemctl-restart-crio` | System | `Exec` |
| `systemctl-restart-kubelet` | System | `Exec` |
| `systemctl-start-crio-prune` | System | `Exec` |

これらは、そのビルド上のノードに対するカタログ探索から、名前とティアのみで一覧表示されています。このテナントではこれらのコマンドを実行できないため、ここにはキャプチャされた出力がありません。なお、9 つのうち 4 つはライブデータプレーン上のサービスを再起動することに注意してください。

<Aside type="note" title="サーフェスの変化を検出する">
サーフェスはソフトウェアビルドとともに拡大するため、カタログはそのビルドを記録し、`scripts/capture-sitecli.sh --check` はビルドの変更を、追加または削除されたコマンドとは別にレポートします。これらのノードがアップグレードされると、このチェックによってこれらの 9 つのコマンドが追加されたことがわかります。
</Aside>

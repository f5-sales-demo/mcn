[コマンドリファレンス](../commands/) は各コマンドの機能ごとに整理されています。こちらは何が問題になったかによって整理されています。

| 症状 | ワークフロー |
| --- | --- |
| サイトがオンラインにならない、またはテナントから切断された | [登録](./registration/) |
| ルートがアドバタイズまたは学習されない；VIP に到達できない | [BGP](./bgp-diagnostics/) |
| トラフィックがノードに到達するが届かない | [データプレーン](./dataplane-diagnostics/) |

各ステップはコマンドを文書化したページへのリンクとなっています。ここでは何も繰り返さないため、構文は正確に 1 か所にのみ存在し、ノードとの整合性がずれることはありません。

## 始める前に

どのアクセスパスを使用しているかを確認してください。それによって可能な操作が変わります：

```bash
curl -sS -H "Authorization: APIToken $XCSH_API_TOKEN" \
  "$XCSH_API_URL/api/config/namespaces/system/sites/<site>" | jq -r '.spec.site_state'
```

`ONLINE` は [デバッグ API](../access/debug-api/) が応答することを意味します。それ以外の場合は [シリアルコンソール](../access/serial-console/) を意味し、登録ワークフローが必要なものとなります。

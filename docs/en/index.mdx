**F5 Distributed Cloud Multi-Cloud Networking** (MCN) connects distributed workloads across public clouds (AWS, Azure, GCP), on-premises hypervisors, and edge sites using automated Layer 3 and Layer 7 overlays.

## Architecture

```text
+-------------------------------------------------------------------------+
|                  F5 Distributed Cloud Global Network                    |
|                                                                         |
|  +--------------------+                     +--------------------+      |
|  | AWS VPC Site       | <=================> | Azure VNet Site    |      |
|  | Customer Edge (CE) |   Global Backbone   | Customer Edge (CE) |      |
|  +---------+----------+   (IPsec / Wireguard) +---------+----------+      |
|            |                                            |               |
|            v                                            v               |
|  +--------------------+                     +--------------------+      |
|  | Private Subnet AWS |                     | Private Subnet Azure|     |
|  | Workloads / APIs   |                     | Workloads / DBs    |      |
|  +--------------------+                     +--------------------+      |
+-------------------------------------------------------------------------+
```

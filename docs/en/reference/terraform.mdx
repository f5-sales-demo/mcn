from `docs/_includes/terraform`; do not copy resource definitions into prose.

## AWS Route Server

`aws_vpc.tf` creates the VPC association, endpoints, and route propagation. `aws_ce.tf` creates the
three independent CE peers and test client. `aws_xc.tf` creates their F5 site and application path.

## KVM Customer Edge

`variables_kvm.tf` defines the F5 image and local network inputs. `kvm.tf` creates the supported CE
domain, FRR peer, and client. `onprem_kvm.tf` creates the matching F5 site and BGP objects.

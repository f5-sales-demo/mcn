<Aside type="note" title="Detecting the surface moving">
Because the surface grows with the software build, the catalog records the build it
came from, and `scripts/capture-sitecli.sh --check` reports a build change
separately from added or removed commands. When these nodes are upgraded, that check
is what tells you these nine arrived.
</Aside>

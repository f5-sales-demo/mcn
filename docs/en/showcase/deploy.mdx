title: Deploy the full showcase
description: Plan and deploy all default MCN showcase paths.

---

Run a plan before you create resources. Confirm that the AWS Route Server, three AWS sites, KVM
CE, FRR peer, and local client appear alongside the Azure and Canadian resources.

1. Initialize Terraform with your backend configuration.

   ```bash
   terraform -chdir=terraform init -backend-config=backend.hcl
   ```

2. Save and review the complete plan.

   ```bash
   terraform -chdir=terraform plan -out=showcase.tfplan
   ```

3. Apply the approved plan.

   ```bash
   terraform -chdir=terraform apply showcase.tfplan
   ```

Terraform creates each Secure Mesh v2 site, issues one site-scoped cloud-init credential, and then
boots its node. Registration proceeds automatically. A second apply is not part of the deployment
contract.

If a KVM image is unavailable, stop. Do not present an incomplete full showcase.
